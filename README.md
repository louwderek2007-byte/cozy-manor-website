# Cozy Manor Guest Rooms

Premium hospitality redesign for Cozy Manor Guest Rooms in Lyttelton Manor, Centurion.

## Project structure

- `index.html` – main landing page
- `rooms.html` – rooms listing
- `room-detail.html` – detailed room page
- `gallery.html` – editorial gallery
- `styles.css` – full site styling
- `script.js` – interactions and lightbox
- `robots.txt` – SEO guidance
- `sitemap.xml` – sitemap

## Local preview

Open the HTML files directly in a browser, or run a local static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
